# Zen CLI 通路加固（2026-11-01）

## 再次故障后的补充修复

现场代理 `127.0.0.1:18549` 被拒绝，同一应用下有两个 mihomo；属于本地出口生命周期
故障。现在 sync/stop 串行执行、等旧进程退出后复用端口、监听就绪才发布端口，意外退出
后下一次 sync 修复。五分钟刷新、订阅刷新、池变更均同步 CLI 出口，仍可用的当前出口
优先保留。CLI 请求前检查旧端口，生成期间延后后台内核/CLI 重启，结束后统一同步。

模型页：连接正常绿色、最近调用失败橙色、预热中蓝灰色，附状态文本。

验收：最终全量 339 通过/2 跳过；新增请求保护定向测试 20 通过。真实 DeepSeek 非流式与
流式在中间版本返回上游 `Free usage exceeded`（429）。最终安装版本非流式返回 HTTP 200、
正文 `OK`，耗时 34.28 秒，输入 8361 / 输出 3 token。随后同模型流式 HTTP 200，7.31 秒，
正文包含 `OK`、完整 `[DONE]`、无 error 帧。部分飞鸟云节点访问推理目录仍会失败；
应区分本地旧端口、节点故障与明确的上游额度拒绝，单次成功不保证上游持续放行。

面向的问题是：Zen 在探测里「可用」，真实调用却失败。本文的每条都对应一次实测或
一次回归用例，不包含仅为推测的改动。

## 1. 本地控制面 ≠ 出网面

Zen CLI 的控制地址是回环（`127.0.0.1:4097`），但 CLI 自己要出网到 opencode.ai。
旧启动逻辑把「回环供应商」当作「不需要出口」，在启动时清掉了它们的代理池绑定，
于是 CLI 退回家宽直连——家宽出口的免费额度往往已经烧穿，表现为
`Free usage exceeded`。

现在用 `UpstreamDef.supportsUpstreamEgress` 区分两类回环：随包号池（本地控制、
本地出网）保持直连；Zen CLI（本地控制、需出网）保留代理池绑定。

## 2. 出口配置与内核端口漂移

内置 mihomo 重启后会重新分配 listener 端口，Zen CLI 进程里的 `HTTP_PROXY` 不会
跟着变，出口会静默失效（CLI 报 `Cannot connect to API`）。现在池变化、内核同步
完成后都会重新解析 Zen 出口并按需重启 CLI 进程（`_syncZenCliEgress`）。

## 3. 探活目标要对齐真实目标

默认探活目标 `cp.cloudflare.com/generate_204` 只能证明「节点能出网」；实测同一批
节点里能过该探活的仍可能打不开 opencode.ai。现在按用途登记真实目标
（`upstream:zen` → `https://opencode.ai/`），定向探活失败的节点在该用途的轮换候选
里被剔除，其它用途不受影响。

## 4. 连不通也要换出口，并原地重试一次

额度耗尽与出口不可达都会导致调用失败，但含义不同：前者是「这个出口今天用完了」，
后者是「这个出口根本到不了 API」。两者都换出口，记账口径不同（额度烧穿记额度，
连不通记该用途失败）。

CLI 通路的请求在提交响应之前失败时，换节点重启 CLI、等新进程就绪后原样重发一次，
客户端无感；只换一次，避免无限轮换。两次都失败才如实回报 429/502。

## 5. 目录可达 ≠ 模型可生成

`/v1/models` 里除目录健康外新增 `catalog_healthy` 与 `last_call_error`：某个模型
最近一次真实调用失败会被记录，界面与客户端据此区分「目录里有」和「能生成」。

## 6. 会话隔离与清理

事件流按嵌套 `sessionID`（`properties.info.sessionID` / `properties.part.sessionID`）
过滤，之前只看顶层 `sessionID`，并发请求可能串流；请求结束（含失败）后删除临时
会话，避免 CLI 侧堆积。

## 7. Anthropic 流式格式

CLI 通路接到 `/v1/messages` 流式请求时，之前仍输出 OpenAI 的 `chat.completion.chunk`，
Claude Code 一类客户端会判为不可用。现在经 `AnthropicStreamTransformer` 输出原生
Anthropic 事件序列。

## 不能靠 CLI 解决的部分

`Free usage exceeded` 是上游明确的额度拒绝，不能仅凭这句话推断计量维度和恢复时间。
应用应记录原文并返回 429；配置、网络连通和额度授权分别验收。本地修复不能保证上游
放行，不应把目录或首页可达标为生成成功。
